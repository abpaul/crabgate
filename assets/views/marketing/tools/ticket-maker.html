How the sum works

Use this page for a small event where you want paper tickets. Enter the event name, date and time, venue, ticket type and price. The price is a label, so include the currency you want printed. Nothing here takes a payment or records a sale.

Choose up to 200 tickets and the first number. Each ticket gets one number and a matching tear-off stub. The last number is first number plus ticket count minus one. Keep the stub when someone enters if you need a simple paper record. A number is not proof that a ticket was paid for.

The print layout puts eight tickets on each page, in two columns and four rows. Use A4 or Letter paper, portrait, at 100% scale. Turn off the browser’s headers and footers. The last page can have fewer than eight tickets. Check a test sheet before printing the whole run, then cut between the tickets.

You can add a short QR text, such as an event address. Every ticket uses the same QR text. CrabGate draws that code through a small request; the text is not saved. Without a QR code, the details stay in your browser.

These tickets are not checked at the door by any system. Copies can carry the same number. CrabGate tickets are checked at the door, so staff can see whether a ticket has already been used. Use this maker only when a paper list and stubs fit your event.

Worked example

Eight tickets starting at 101 are numbered 101 to 108. Nine tickets use two print pages: eight on the first page and one on the second.
