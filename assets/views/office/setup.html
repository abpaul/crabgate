Connect Stripe

Stripe takes the card payments, and the money lands in your own Stripe account. We never hold it. To connect the two, you give CrabGate a key from Stripe. This is the only step. We set up the rest in your Stripe account for you.

{% if key_tested %}

Connected. Your key ends in …{{ key_last }}. Paste a new one below if you ever need to replace it.

{% endif %}
  1. Sign in to your Stripe dashboard and open the API keys page.
  2. Copy your secret key. It starts with sk_.
  3. Paste it here. We check it with Stripe straight away, then create the webhook that tells us when someone pays.

Prefer a restricted key? It starts with rk_. Give it write access to Checkout Sessions, Refunds, and Webhook Endpoints. Without write access to Webhook Endpoints, we still save your key, but you set up the webhook by hand.

Buyers can pay with any method you switch on in Stripe. For events that sell out, keep to methods that confirm at once.

We store it encrypted. No Stripe account yet? Create one at stripe.com, then come back.
